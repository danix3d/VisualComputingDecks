Rotation and Scaling

Rotation about the origin, counter-clockwise for θ > 0; the dashed outline is the original house. Drag θ through 90° and 180° and read the matrix: the columns are the images of the x and y axes. Uniform scale s multiplies the upper-left 2×2 block and commutes with the rotation. The last row stays [0 0 1]: this is an affine map.

Interpolation X

A 24×24 crop, magnified 30×
The same 24×24 pixels (the astronaut's eye), resampled at every screen pixel. Nearest neighbor: blocks. Bilinear: faint star-shaped artifacts along diagonals, visibly softer. Bicubic (Keys, a = −½): sharper, with slight overshoot at edges.

Bilinear vs. Bicubic Displacement

source
output
The grid is in the output (right): each vertex stores where it fetches from in the source, and the handles on the left are those positions. Drag a handle; double-click the source to reset. The red curves on the left are the sample positions x + d(x) along the output grid lines. Same vertex displacements, two ways to interpolate d between vertices: bilinear d has discontinuous derivatives across cell boundaries, so the checkerboard creases along the grid lines. Bicubic d is smooth.
